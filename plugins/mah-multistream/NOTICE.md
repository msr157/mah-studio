# MAH Multistream

In-tree multistream dock for MAH Studio, based on  
[obs-multi-rtmp](https://github.com/sorayuki/obs-multi-rtmp) by 雷鳴 / SoraYuki (GPL-2.0).

Brand + dock id changed to `mah-multistream`. Core push/output logic is upstream.

Add targets for YouTube / Twitch / Kick Custom RTMP. Never paste stream keys into chat.
