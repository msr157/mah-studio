# MAH docks (browser)

Add in OBS: **View → Docks → Custom Browser Docks**.

| Dock | Local path / URL |
|---|---|
| Starter | `mah/starter/index.html` (file://…) |
| Multichat help | `mah/docks/multichat-help.html` |
| Twitch chat | Official popout for your channel |
| YouTube chat | Live chat popout while streaming |
| Kick chat | Official chatroom popout (read-only send) |

Installer that wires docks + lock + multi-rtmp for a stock OBS install:  
https://github.com/msr157/mah-obs
