# Layout presets

| File | Use |
|---|---|
| `layout-loved.json` | Vertical chat column + locked docks |
| `Apply-MahLayout.ps1` | Writes into `%AppData%\obs-studio\user.ini` (quit OBS first) |

Also applied from **MahOnboarding → Loved layout** when the JSON is found relative to the OBS binary or at `D:/Codes/mah-studio/mah/presets/`.
